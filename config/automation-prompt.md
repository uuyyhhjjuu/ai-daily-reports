## 覆盖范围
前一日 22:00 至当日 22:00（北京时间）的全球 AI 动态，中英双语，必须同时覆盖国内与海外。

## 执行步骤
1. 仓库路径：C:\Users\86151\WorkBuddy\自动化任务\ai-daily-reports（git，remote git@github.com:uuyyhhjjuu/ai-daily-reports.git，分支 main，即 GitHub Pages 源）。
2. 确定报告日期 D（运行当日，YYYY-MM-DD）。若 D 的报告已存在，则改为补生成仓库中缺失的最近一个日期。
3. 【信源扫描】先读 ai-daily-reports/config/sources.json，按其 scan_policy 执行：T1 官方一手源逐条必扫（用其 search_hint 或直接访问 url 查当日动态）；T2 权威媒体确保当日重磅事件有覆盖、重要事件两源交叉验证；T3 社区补充早期信号。再用中英文关键词围绕当日焦点补充 WebSearch。严禁编造事实、数字或链接。
4. 【预筛（三态）】对候选逐条判定：PASS＝有明确 AI 相关实质内容（模型/Agent/工具/算力/融资/IPO/监管/研究/观点）；BLOCK＝明确无关，必须给出"确认无关"的正面依据，不得仅因"未提及 AI"淘汰；UNKNOWN＝材料不足，宁可保留待补，不直接丢弃。只有 PASS 进入评分。
5. 【注意力评分】对每条 PASS 候选，五轴各打 0–10 整数：sig 实质份量 / nov 信息增量 / cred 证据强度 / reson 共振面 / act 可用性；独立打两次取平均防漂移。按内容类型加权合成 0–100 分（权重和为10）：model_release 3/2/2/2/1；product_launch 2/2/1/2/3；tool_or_prompt 1/2/1/2/4；research_paper 5/3/1/0/1；industry_event 3/1/2/4/0（本站读者为投资者，共振面已加重）；opinion_analysis 1/3/1/4/1；tutorial_explainer 1/1/1/3/4。压噪声上限：PR 软文/客户案例无量化细节 sig≤4；例行小版本/常规接入 sig≤3；纯预告无实质参数 nov≤3；无数据只说"很惊艳"的二手体验 sig≤4；新闻合集类无单一焦点 sig≤3；纯论文微创新 sig≤4。
6. 【入选与排序】≥60 分进正文各章节，40–59 分仅进"当日要闻表"，正文最终 25–40 条。同分 sig 优先。正文按注意力分降序排列；每张卡片的 meta 区显示注意力分（如"score 78"）；当日最高分的 3 条在报告头部"今日焦点"区做一句话导语（答案先行：先给结论再给细节）。对比最近 7 天已有报告：同一事件的实质新进展在标题前标"⬆"，全新事件标"🆕"。
7. 【防幻觉】写卡片时严格遵守：不添加来源原文没有的功能/数字/版本/默认值/限制；不确定的细节宁省略，不"听起来合理地补全"；原文用相对时间就照抄，绝不换算成绝对年份（补生成历史报告除外，统一用绝对日期）；不得强化语气或范围（"正在探索"≠"已经采用"）；"首次/唯一/完全/独立"等排他性表述必须原文明示才能保留；摘要中每个产品名/数字/版本号必须能在来源中找到。
8. 【生成报告】以仓库中最近一份报告为模板（如 ai-daily-reports/2026-09/AI每日报告-2026-09-06.html），沿用其 CSS、章节结构与交互（含 Chart.js 图表、章节折叠）。章节依次为 今日焦点 / 当日要闻表 / 模型与芯片 / 产品与应用 / 资本与 IPO / 政策与产业 / 安全与研究 / 观点与 KOL。每张卡片含：中文详情 + "EN:" 英文摘要 + 来源（媒体名与日期）+ 可点击原文链接 + 注意力分。
9. 原子同步更新 ai-daily-reports/index.html：按时间倒序插入当日条目，月分组标题为「📅 2026 年 X 月」。索引与报告必须在同一次 commit 中提交。
10. git add / commit / push 到 main 分支。注意：若沙箱拦截 ~/.ssh 导致 push 静默失败，必须用绕过沙箱（dangerouslyDisableSandbox）的方式重新执行 git push，并验证 push 输出中出现 "main -> main"。

## 硬性要求
- 实时生成的报告，时间格式用「X小时前 / 今天HH:MM / 昨天HH:MM」；若补生成历史日期则用绝对日期（如 8/31）。
- 不生成 PDF（2026-08-20 起已停用）。
- 完成后只回报 GitHub Pages 主页链接与当日报告直链，并附当日 Top3 焦点的一句话摘要，不要输出冗长正文。
